# Joho1-01: 情報社会の問題解決

高等学校「情報Ⅰ」の最初の章。科目全体の導入として位置づけられ、後続の第2章（コミュニケーションと情報デザイン）・第3章（コンピュータとプログラミング）・第4章（情報通信ネットワークとデータの活用）で個別に深掘りする内容を、「情報と情報技術を使って問題を発見し解決する」という一本の軸でつなぐ役割を持つ。情報そのものの特性、問題解決の進め方、情報セキュリティ、法規・情報モラル、情報社会の光と影、情報技術の発展という、情報社会を生きるうえでの前提知識を広く扱う。

!!! info "出典・凡例"
    出典: 文部科学省「高等学校情報科『情報Ⅰ』教員研修用教材」第1章 情報社会の問題解決（`JohoI/02_第1章_情報社会の問題解決.pdf`）。

## 全体像 {#overview}

**中心の問い**: 情報社会で問題を見つけて解決するには、何を知っていなければならないか。

この章の5つの節は、上の問いに答えるための土台を異なる角度から示している。

| 節 | この節が答える問い | なぜ学ぶか（日常での場面） | 本文リンク |
|---|---|---|---|
| 1. 情報とメディアの特性・問題解決 | 情報とは何か。問題をどう定義し、どんな手順で解決に近づくか | 「なんとなく困っている」を言葉にして、ブレーンストーミングやKJ法で整理する場面 | [1. 情報とメディアの特性、問題の発見・解決](#info-media-problem-solving) |
| 2. 情報セキュリティ | 何を、誰から、どこまで守るべきか | パスワードの使い回し、フィッシングメール、公衆無線LANの利用 | [2. 情報セキュリティ](#info-security) |
| 3. 法規・情報モラル | 著作物や個人情報を扱うとき、何が許され何が許されないか | 授業資料のコピー、SNS投稿に写り込んだ他人の顔や個人情報 | [3. 情報に関する法規、情報モラル](#law-moral) |
| 4. コミュニケーションの光と影 | 情報技術の普及は何をもたらし、何を失わせているか | SNS依存、デジタルデバイド、ネット上のトラブル | [4. 情報社会におけるコミュニケーションの光と影](#communication-light-shadow) |
| 5. 情報技術の発展 | 新しい情報技術は生活・産業・社会をどう変えつつあるか | キャッシュレス決済、セルフレジ、IoT家電、スマート農業 | [5. 情報技術の発展](#tech-development) |

**表の読み方**

- 1節の「問題解決」（問題発見 → 情報収集・分析 → 解決策の探索 → 実行 → 振り返り）は、2〜5節すべてを貫く共通の考え方になっている。
- 2節の情報セキュリティは、CS2023の [NC-Security §1](../NC/NC-Security.md#threats-vulnerabilities-countermeasures) が扱う「CIAトライアド」（機密性・完全性・可用性）と同じ枠組み。
- 4節で見えてくる課題（デジタルデバイドなど）は、1節の問題解決の手順を使って分析・改善していく対象、という関係にある。
- 次章の [Joho1-02](Joho1-02.md) では、この章で見つけた問題の解決策を「他者に伝える」段階に焦点が移る。

## 1. 情報とメディアの特性、問題の発見・解決 {#info-media-problem-solving}

**情報の成り立ちと特性**

- 事象や現象を数字や文字などで記号化したものが **データ**、そこに意味や価値が付加されたものが **情報**、得られた情報を分析・蓄積したものが **知識**。情報のやりとりを媒介するもの（文字・音声・静止画・動画や、郵便・電話・新聞・インターネットなど）を **メディア** という。
- 情報には「もの」と対比したときに際立つ4つの代表的な特性があるとされる。
    1. **形がない**：見えないため、受け取った側が各自で解釈する必要があり、人によって解釈が変わりうる。
    2. **消えない**：内容が複製されて伝わっても元の情報は残り続け、複製されたかどうか自体が分かりにくい。
    3. **簡単に複製できる**：特にデジタル媒体は複製のコスト・手間が小さい。
    4. **容易に伝播する**：ネットワーク経由で瞬時に広い範囲へ伝わりうる。

**問題の発見・明確化と問題解決の流れ**

- 「問題」は「あるべき理想の姿と現実とのギャップ」や「解決や解消を必要とする状況」を指す。ゴール（理想の姿）や解決手段があらかじめ明示されているものは「課題」と呼ばれることがあり、これに対して、自分でゴールを設定し解決の手段も自分で検討しなければならないものが（狭い意味での）「問題」にあたる。
- 教材が示す問題解決の流れ：**問題の発見 → 情報の収集と分析・問題の定義 → 解決方法の探索・計画の立案 → 結果の予測・計画の実行 → 振り返り → 次の問題解決へ**、という循環的な進め方（PDCA サイクルなどもこの一種として挙げられている）。
- ゴール（理想の姿）を明確に設定することが、単なる「調べただけ」に終わらせず、主体的に考え・判断しながら解決に近づくための鍵になるとされる。

**情報の可視化と新たな情報の創出**

見えないアイデアや考えを言葉で表現（記号化）して可視化するための代表的な手法として、以下が紹介されている。

| 手法 | 内容 |
|---|---|
| **ブレーンストーミング** | 米国の広告代理店 BBDO 社の A・F・オズボーンが考案したとされるアイデア発想法。「質より量」「制約を設けない」「便乗の奨励」「批判の禁止」の4ルールがある |
| **KJ法** | アイデアをカードに記し、二次元に配置しながらグループ化・表題づけ・関連づけして意味を見いだす |
| **ロジックツリー／コンセプトマップ** | 項目を一定のルールで線でつなぎ、関連や階層を分かりやすく示す |
| **座標軸／マトリクス表** | 2つの評価項目を軸にとり、アイデアや選択肢を配置・採点して比較検討する |

**問題解決と情報の発信・振り返り**

- 振り返りと情報発信は問題解決を繰り返し改善していくための重要な場面であり、他者からのフィードバックを得る機会でもある。
- 発表方法にはペアでの口頭発表・グループ内口頭発表・全体への口頭発表・ポスター発表・Web での発表などがあり、それぞれ手軽さと参加の重みづけ、共有範囲、準備の手間にトレードオフがある。
- 教材は、問題解決学習を授業で扱う際の設計観点（グループの人数、確保する時間、問題のレベルや自由度、前提知識・フィールドワークの扱い、進行管理の度合い、発表形式、振り返りの方法）にも触れており、これらは章末の「全体を通じた学習活動の進め方」で改めて整理されている。

## 2. 情報セキュリティ {#info-security}

**サイバー犯罪**

- 警察白書（平成30年）による3類型：**不正アクセス禁止法違反**、**コンピュータ・電磁的記録対象犯罪等**、**ネットワーク利用犯罪**。
- ネットワークを利用した犯罪の特徴として、①匿名性が高い、②（ログ以外の物理的証拠が残らないため）痕跡が残りにくい、③不特定多数が被害を受けうる、④時間と空間の制約がない、の4点が挙げられている。

**情報セキュリティの3要素とその他の要素**

- 情報セキュリティとは、情報の **機密性 (Confidentiality)**・**完全性 (Integrity)**・**可用性 (Availability)** を確保すること。どの要素をどこまで確保するかは、導入・運用コストとのトレードオフを踏まえて情報システムごとに検討する必要があるとされる。
- 2006年制定の JIS Q 13335-1 では、さらに **真正性 (authenticity)**・**責任追跡性 (accountability)**・**信頼性 (reliability)**・**否認防止 (non-repudiation)** を加えた7要素という整理もある（JIS Q 13335-1 はのちに JIS Q 27000 シリーズに置き換えられた）。
- これらを実現する技術として認証が欠かせず、パスワードに加えて生体認証（指紋・虹彩・静脈など）が用いられる。知識情報・所持情報・生体情報のうち異なる種類の要素を2つ組み合わせるものを **二要素認証** といい、認証の手順が2段階に分かれていること（同じ種類の要素を順に2回入力する場合も含む）を指す **二段階認証** とは別の概念である。

**マルウェアと技術的対策**

- 不正かつ有害な動作を行うソフトウェアの総称を **マルウェア** といい、代表例として、正規・有用なプログラムに見せかけて隠れた不正機能を持つ **トロイの木馬**、独立して活動し自己増殖する **ワーム**、他のファイルに寄生して自己増殖する **狭義のウイルス** に大別される。
- 技術的対策として、ウイルス対策ソフトウェアの導入とウイルス定義ファイルの更新、OS・アプリケーションソフトウェアを最新の状態に保つこと（セキュリティホールへの対処）、ファイアウォールの導入が挙げられている。

**組織としての対応・ユーザーの心構え**

- 組織では、「なぜ情報セキュリティが必要か」を示す **基本方針**、それを実践する **対策基準**、具体的な手続きを定める **実施手順・運用規則** の3層からなる情報セキュリティポリシーを整備し、構成員全体で運用する必要がある。
- 個人の側でも、ターゲットを絞った「標的型メール攻撃」や、技術的な脆弱性だけでなく人の心理・行動上の弱点を利用して情報を盗み出す **ソーシャルエンジニアリング**（なりすまし電話、肩越しに覗き見る「ショルダーハッキング」、ごみ箱を漁る「トラッシング」、メールや偽Webサイトで認証情報等をだまし取る「フィッシング」など）への注意、公衆無線LANの通信が傍受されうることへの理解、https による暗号化通信の利用などが心構えとして挙げられている。

## 3. 情報に関する法規、情報モラル {#law-moral}

**知的財産権**

- 知的財産権は、申請が必要な **産業財産権**（特許権・実用新案権・意匠権・商標権。特許庁への出願・登録で権利が発生する）と、申請が不要な **著作権** に大きく分けられる。
- 著作権法第35条により、教育を担任する者・授業を受ける者は、原則として営利を目的として設置されているものを除く教育機関において、公表された著作物を、授業の過程で利用するために必要と認められる限度で複製できる（ただし著作権者の利益を不当に害する使い方は違法）。

**個人情報の保護**

- 2003年成立・2005年全面施行の個人情報保護法（3年ごとの見直し規定あり）は、個人情報を「生存する個人に関する情報であって、氏名・生年月日その他の記述等により特定の個人を識別できるもの（他の情報と容易に照合することができ、それにより特定の個人を識別できることとなるものを含む）、または個人識別符号が含まれるもの」と定義している。
- 歴史的経緯として、19世紀末に米国のウォーレンスとブランダイスが主張した「プライバシーの権利」（私生活をみだりに他人の目にさらされない権利）、1967年にウェスティンが述べた「自己に関する情報をコントロールする権利」という考え方があり、OECD（経済協力開発機構）の **プライバシー8原則**（収集制限・データ内容・目的明確化・利用制限・安全保護・公開・個人参加・責任の各原則）を経て、日本の個人情報保護法整備につながった。
- 個人情報は本人の同意なく第三者へ提供してはならないのが原則だが、法令に基づく場合や、人の生命・身体・財産の保護に必要があり、かつ本人の同意を得ることが困難な場合など、例外的に同意なしで提供できる場合が定められている。また、特定の個人を識別できないよう加工し元に復元できなくした **匿名加工情報** として、データの利活用を進める仕組みもある。

## 4. 情報社会におけるコミュニケーションの光と影 {#communication-light-shadow}

- 教材が示す統計では、2008年ごろにパソコンの世帯保有率がおよそ85%に達した後、2010年以降スマートフォンが急速に普及し、2017年には世帯保有率がパソコンを上回った。SNS（mixi・Facebook・LINE・Twitter 等）の普及とあいまって、10代は電子メールよりもソーシャルメディアの利用が突出している、という調査結果が紹介されている。
- 情報技術の発展はコミュニケーションの利便性を高める一方で、年齢や所得などによる利用機会・利用量の格差（**デジタルデバイド**）、情報機器の利用に伴う身体的症状や依存的な状況（**テクノストレス**）、SNS に起因する事犯の被害児童数の増加といった負の面も生じていると教材は指摘している。
- 情報社会は光と影の両面を持つが、影があるからといってインターネットのない社会に戻ることは現実的ではなく、§1 で扱った問題解決の考え方を用いて影の面を明確化・分析し、情報や情報技術を効果的に使いながら減らしていく姿勢が重要だと教材はまとめている。

## 5. 情報技術の発展 {#tech-development}

**支払い方法の変化**

- 電子マネーにはプリペイドカード型・IC カード方式（Suica・楽天Edy など）・センター管理型があり、現金への交換可否や残高の記録場所、暗証番号の要否、支払いのタイミングなどの点でデビットカード・クレジットカードとも異なる。
- 交通系 IC カードや電子マネー、ID カードなどに広く使われる非接触型 IC カードの技術方式として **FeliCa** が紹介されている。QR コード決済や、カメラ・センサ・AI を活用した「レジなし決済」（無人店舗）の登場にも触れている。

**働き方の変化**

- スーパーマーケットなどで普及してきたセルフレジには、レジ係がバーコードをスキャンし支払いだけを客が行う **セミセルフレジ** と、スキャンから支払いまで客が行う **完全セルフレジ** があり、それぞれにメリット・トレードオフがある。
- 農業就業者の減少・高齢化を背景に、IoT や AI を活用した **スマート農業**（農業機械の自動走行、センシング技術を用いた精密農業、重労働のアシスト、栽培ノウハウのデータ化、生産情報の提供）の取り組みが紹介されている。

**生活の変化**

- センサとコンピュータが組み込まれた様々な「モノ」が（有線・無線を問わず）通信でインターネットに接続される **IoT (Internet of Things)** により、「いつでも、どこでも、何でも、誰でも」ネットワークにつながる社会（ユビキタスネットワーク社会）が実現しつつある。
- 大量のデータを統計学的手法などで分析し、データ相互の関係や知見を見いだすことを **データマイニング** という。IoT の普及によりモノがインターネットにつながることで収集できるデータも、その分析対象の一つである。個人情報保護法の改正で導入された匿名加工情報は、こうしたデータ利活用とプライバシー保護を両立させる仕組みとして位置づけられている。
- **AI（人工知能）** は、人間の神経細胞を模した多層ニューラルネットワークを用いてコンピュータに大量のデータから自動的に学習させる **ディープラーニング（深層学習）** という手法によって近年性能が向上しているが、教材は「まだ発展途上である」と述べるにとどめている。
- 障がいの有無・年齢・性別等にかかわらずすべての人にとって使いやすいものを最初からデザインする **ユニバーサルデザイン** は、既存の障壁（バリア）を後から取り除く **バリアフリー** とは別の考え方として整理されている。

## 学習目標 {#learning-outcomes}

教材冒頭の「学習目標」より：

- 情報やメディアの特性を踏まえ、情報の科学的な見方・考え方を働かせて、情報と情報技術を活用して問題を発見・解決する学習活動を通して、問題を発見・解決する方法を身に付ける。
- 情報技術が人や社会に果たす役割と影響、情報モラルなどについて理解し、情報と情報技術を適切かつ効果的に活用して問題を発見・解決し、望ましい情報社会の構築に寄与する力を身に付ける。
- 情報社会における問題の発見・解決に情報と情報技術を適切かつ効果的に活用しようとする態度、情報モラルに配慮して情報社会に主体的に参画しようとする態度を身に付ける。
