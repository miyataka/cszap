### 講評

- Q20 は「L2 では経路（フレームの転送先）はどう決まるか」という**スイッチのフォワーディング判断**を問う設問に対し、**ARP（IP アドレスから MAC アドレスを解決する仕組み）**で答えてしまっている。ARP は「送信側が次ホップの MAC アドレスを**知る**手段」であり、L2 スイッチが「届いたフレームをどのポートへ**転送するか**決める仕組み」（学習型ブリッジ）とは別の問い。両者は隣接していて混同しやすいので、次回は「ARP＝宛先 MAC を知る」「学習型ブリッジ＝知った宛先 MAC でどのポートに出すか決める」と対で覚え直す。

**Q20.** L2 (リンク層) では経路はどう決まるか?

??? note "回答・模範解答・採点を開く"

    **本人の回答**

    > ARPプロトコルでIPアドレスに対してMACアドレスを返してきたマシンやルーターにパケットを送りつける

    **模範解答**

    L2 スイッチは**学習型ブリッジ (learning switch)** として動作する：フレームが届くと**送信元 MAC アドレス**を見てその MAC がどのポートの先にいるかを学習し、宛先 MAC アドレスがすでに学習済みならそのポートだけへ転送し（未学習ならすべてのポートへフラッディング）、こうして**フレームを次ホップへ届ける経路（＝出力ポート）が決まる**（[§5-学習型ブリッジ](NC-SingleHop.md#learning-switch)）。**ARP** はこれとは別の問題——**送信側ホストが、次ホップの IP アドレスに対応する MAC アドレスをまだ知らないときに、それを解決する**手順であり、[『指定テキスト対応表』](NC-Textbook-TCPIP.md)にあるとおり本サイトでは L2/L3 境界の話として明示的な節を持たない。

    **採点 0.4 / 1.0** — ARP の役割自体は正しく説明できているが、設問が問う「**スイッチが転送先ポートをどう決めるか**」（学習型ブリッジの動作）には答えられておらず、隣接する2つの仕組みを混同している。
